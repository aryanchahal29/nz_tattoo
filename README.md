# Black Heron — Tattoo & Piercing Atelier

> **Bespoke fine-line tattooing, custom blackwork & implant-grade body piercing.**  
> 244 Karangahape Road, Newton, Auckland 1010, Aotearoa New Zealand.

---

## ✨ Overview

**Black Heron** is an editorial-grade, boutique tattoo and piercing atelier website crafted with modern web standards, fluid typography, smooth locomotive scrolling, and interactive booking flows.

- **Design Aesthetic:** Neo-editorial dark luxury (Ink `#0d0f12`, Ivory `#f5f2eb`, Oxblood `#7a1c1c`, Brass `#c49a45`).
- **Typography:** *Anton* (expressive, condensed display), *Cinzel* (classical headings), *Cormorant Garamond* (editorial accents), *Plus Jakarta Sans* (refined UI copy).
- **Core Stacks & Libraries:** Vanilla HTML5, Modern CSS custom properties, JavaScript (ES6+), GSAP & ScrollTrigger, Lenis smooth scrolling.

---

## 🎨 Key Features

- **Kinetic Hero & Marquee Bands:** Dynamic intro counter, badge rotation, and dual high-contrast marquee bands.
- **Interactive Portfolio & Filtering:** Categorized gallery for fine line, micro-realism, neo-traditional, heavy blackwork, and curated piercings.
- **The Standard:** Studio protocol presentation with sterile single-use equipment standards (ZERO cross-contamination, F-136 implant-grade titanium).
- **Session Calculator & Pricing:** Dynamic sliders and estimators for tattoo sessions and piercing procedures.
- **Multi-Step Consultation Wizard:** Step-by-step interactive booking modal for quotes and appointment scheduling.

## 🚀 Getting Started

To run the site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/aryanchahal29/nz_tattoo.git
   cd nz_tattoo
   ```

2. Open with any local web server:
   ```bash
   # Python 3
   python -m http.server 8080

   # Or with Node.js
   npx serve .
   ```

3. Open your browser at `http://localhost:8080`.
